# Shuvai Incorporated – 3D bathroom showroom

Built on the HUMA showroom framework. React + Vite + three.js 0.128.

    npm install
    npm run dev

Deploy: Cloudflare Pages, build `npm run build`, output `dist` (set NODE_VERSION=20 if needed).

## Before going live
- `src/config.js`: confirm the WhatsApp number (three different numbers appear on Shuvai's adverts), prices and address.
- `public/img/`: replace the screenshot crops with Shuvai's own product photos (same file names).
